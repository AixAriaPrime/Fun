# Empire of Free LLMs — web

Minimalistic React + Vite + TypeScript chat UI for the Empire of Free LLMs.

- `npm run dev` — start the dev server (proxies `/api` to the backend).
- `npm run build` — type-check and build to `dist/`.
- `npm run lint` — run oxlint.

See the [root README](../README.md) for the full setup, including how to run the
backend and enable real providers (OpenRouter / Ollama).
